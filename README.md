# My portfolio

Plain HTML and CSS, no framework. This is my web dev project for the course.

Two files basically. `index.html` has everything, `style.css` has all the styling.

## files

- `index.html` - about me, skills, projects, college table and a contact form
- `style.css` - all the styling
- `images/my-photo.jpg` - my photo (right now it is a grey placeholder, need to change it)

## topics covered

- HTML structure, links, images, headings
- lists, tables and forms
- CSS selectors, colours, box model
- display, flexbox, media queries
- responsive layout with grid
- specificity, inheritance, positioning

## running it

Just open `index.html` in a browser, or use live server in vs code.
